# Data Structures and Algorithms

Implementation of core data structures and algorithms from scratch in Python 3, each accompanied by time and space complexity analysis. This repository is maintained primarily for personal learning purposes and does not aim to cover every data structure or algorithm in the field.

> **Note**: This repository is currently under development. Complexity analyses and additional algorithms will be added over time.

## Running the Code

Each file is self-contained and includes example usage and/or runtime benchmarks. For example:

```bash
python 03_sorting/insertion_sort/insertion_sort.py
```

Output:

```text
Runtime comparison across two versions of insertion sort:

| Input Case      | v1           | v2 (Early Exit) |
|-----------------|--------------|-----------------|
| Already Sorted  |      10.74ms |          0.04ms |
| Almost Sorted   |       9.94ms |          0.13ms |
| Reverse Sorted  |      19.78ms |         19.58ms |
```
